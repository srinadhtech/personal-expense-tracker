# Personal Expense Tracker with CSV

## About
A Python-based Personal Expense Tracker that records daily expenses,
categorizes spending, and stores data permanently in a CSV file.

## Features
- Add daily expenses
- View all expenses
- Calculate total expenses
- Category-wise expense summary
- CSV file storage
- Simple menu-driven interface

## Technologies Used
- Python
- CSV
- File Handling
- DateTime
- OS Module

## How to Run
1. Download expense_tracker.py
2. Run the file using Python
3. Select options from the menu
4. Add and manage expenses
